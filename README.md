This photoalbum is readymade.
There are some problem loading and resizing of pictures in java.
Jpg files load very slowly, but png images are faster.

Use of photoalbum:
choose images,
jpg pictures convert to png,
png files loading into albums
use slideshow or views,
in tableview you can add name and note to all pictures,
data above store in sqlite database
images are stored in different albums as directory
